Logging

Rue provides a powerful structured logging system with support for multiple log levels, JSON/Text formats, and automatic caller information for error tracking.

Environment Modes

Rue supports three environment modes that automatically configure logging behavior:

go 
// Set mode before creating engine
rue.SetMode(rue.DevMode)   // Development (default)
rue.SetMode(rue.TestMode)  // Testing
rue.SetMode(rue.PrdMode)   // Production

// Or use environment variable
// export RUE_MODE=prd

r := rue.Default()
Mode Log Level Format Color Caller Info
DevMode Debug Text Yes Error+
TestMode Info Text No Error+
PrdMode Info JSON No Error+

Log Levels

Rue supports six log levels:

  • Debug - Detailed debugging information
  • Info - General informational messages
  • Warn - Warning messages for potential issues
  • Error - Error messages (includes caller info)
  • Fatal - Fatal errors that cause program exit
  • Stat - Statistics and metrics (includes caller info)

Request Logger Middleware

The request logger middleware logs HTTP requests with timing information:

go 
// Default request logger (uses mode config)
r := rue.Default()  // Includes RequestLogger + Recovery

// Or add manually
r := rue.New()
r.Use(rue.RequestLogger())

// Custom configuration
r.Use(rue.RequestLoggerWithConfig(rue.RequestLoggerConfig{
    Level:        rue.InfoLevel,
    Format:       rue.JSONFormat,
    SkipPaths:    []string{"/health", "/metrics"},
    EnableCaller: true,
    EnableColor:  false,
}))

Standalone Logger

Use the logger independently for application logging:

go 
// Create a custom logger
logger := rue.NewLogger(
    rue.WithLevel(rue.InfoLevel),
    rue.WithFormat(rue.JSONFormat),
    rue.WithOutput(os.Stdout),
    rue.WithCaller(true),
    rue.WithColor(false),
)

// Basic logging
logger.Debug("debug message")
logger.Info("info message")
logger.Warn("warning message")
logger.Error("error message")  // Includes caller info

// Formatted logging
logger.Infof("user %s logged in", username)
logger.Errorf("failed to process request: %v", err)

// Error with error object
logger.ErrorWithErr("database query failed", err)

// Statistics logging (always includes caller info)
logger.Stat("CPU: 17m, MEMORY: Alloc=2.5Mi, TotalAlloc=644484.3Mi")

Structured Logging

Add custom fields to log entries:

go 
logger.WithFields(rue.H{
    "user_id":    123,
    "action":     "login",
    "ip":         "192.168.1.1",
    "user_agent": "Mozilla/5.0...",
}).Info("user logged in")

// Output (JSON):
// {"@timestamp":"2026-01-06T12:30:45.123Z","level":"info","content":"user logged in","fields":{"user_id":123,"action":"login","ip":"192.168.1.1","user_agent":"Mozilla/5.0..."}}

Error Logging with Caller Info

Error and Fatal levels automatically include caller information:

go 
// In handler/user.go line 45
logger.Error("database connection failed")

// Text output:
// [RUE] 2026/01/06 - 12:30:45 | ERROR | user.go:45 | handler.GetUser | database connection failed

// JSON output:
// {"@timestamp":"2026-01-06T12:30:45.123Z","level":"error","caller":"user.go:45","func":"handler.GetUser","content":"database connection failed"}

Statistics Logging

Use Stat level for metrics and statistics:

go 
// Log system statistics
var m runtime.MemStats
runtime.ReadMemStats(&m)

logger.Statf("CPU: %dm, MEMORY: Alloc=%dMi, TotalAlloc=%dMi, Sys=%dMi, NumGC=%d",
    cpuUsage,
    m.Alloc/1024/1024,
    m.TotalAlloc/1024/1024,
    m.Sys/1024/1024,
    m.NumGC,
)

// Output:
// {"@timestamp":"2026-01-06T12:30:45.123Z","level":"stat","caller":"stat/usage.go:61","content":"CPU: 17m, MEMORY: Alloc=2Mi, TotalAlloc=644484Mi, Sys=18Mi, NumGC=381259"}

Package-Level Logging

Use package-level functions for quick logging:

go 
// Use default logger
rue.LogDebug("debug message")
rue.LogInfo("info message")
rue.LogWarn("warning message")
rue.LogError("error message")
rue.LogStat("statistics message")

// Formatted versions
rue.LogInfof("processing %d items", count)
rue.LogErrorf("failed: %v", err)

// Set custom default logger
customLogger := rue.NewLogger(rue.WithFormat(rue.JSONFormat))
rue.SetDefaultLogger(customLogger)

Logger Options

Option Description Default
WithLevel(level) Set minimum log level Based on mode
WithFormat(format) Set output format (Text/JSON) Based on mode
WithOutput(writer) Set output destination os.Stdout
WithCaller(bool) Enable caller info true
WithCallerSkip(n) Skip n stack frames 2
WithColor(bool) Enable colored output Based on mode
WithTimeFormat(fmt) Set time format RFC3339Nano
💡 Best Practice

Use rue.SetMode(rue.PrdMode) in production to automatically enable JSON logging with appropriate log levels.

Environment

Rue supports development and production modes with different default configurations. The mode controls log verbosity, format, and output behavior.

Running Modes

Mode Constant Log Level Log Format
Development rue.DevMode Debug Text
Production rue.PrdMode Info JSON

Setting the Mode

Set the mode via environment variable or in code:

bash 
# Via environment variable
export RUE_MODE=prd
./myapp
go 
// Set in code before creating the engine
rue.SetMode(rue.PrdMode)

r := rue.Default()

Fluent Configuration API

SetMode returns a builder for chaining overrides on top of the mode defaults:

go 
// Production mode but keep debug-level logs
rue.SetMode(rue.PrdMode).
    LogLevel(rue.DebugLevel)

// Development mode with JSON format for log aggregators
rue.SetMode(rue.DevMode).
    Format(rue.JSONFormat).
    EnableColor(false)

// Full customization
rue.SetMode(rue.PrdMode).
    LogLevel(rue.WarnLevel).
    Format(rue.JSONFormat).
    EnableCaller(true).
    EnableColor(false)

Builder Methods

Method Description
LogLevel(level) Override the mode's default log level
Format(format) Override the mode's default log format (Text or JSON)
EnableColor(bool) Enable or disable colored output
EnableCaller(bool) Enable or disable caller information in logs
Override Behavior

Calling SetMode resets all custom overrides. Chain overrides immediately after SetMode, not in a separate statement.

Querying the Mode

go 
mode := rue.GetMode()  // rue.DevMode or rue.PrdMode

if rue.IsDevMode() {
    // Development-only setup
    r.Use(rue.DetailedLogger())
}

if rue.IsPrdMode() {
    // Production-only setup
    r.ErrorHandler = rue.JSONErrorHandler(false)
}

Effective Configuration

Retrieve the resolved config (mode defaults merged with overrides):

go 
config := rue.GetModeConfig()

fmt.Println(config.LogLevel)     // Current effective log level
fmt.Println(config.LogFormat)    // Current effective log format
fmt.Println(config.EnableCaller) // Whether caller info is enabled
fmt.Println(config.EnableColor)  // Whether color output is enabled

Testing

Rue includes a built-in Agent for integration testing without starting a server. It executes requests directly against the engine in-process.

Basic Usage

go 
func TestAPI(t *testing.T) {
    r := rue.New()
    r.GET("/users/:id", getUser)

    agent := rue.NewAgent(r)

    resp := agent.Get("/users/123")
    if resp.StatusCode != http.StatusOK {
        t.Errorf("Expected 200, got %d", resp.StatusCode)
    }

    var result map[string]any
    resp.JSON(&result)
}

Request Methods

The agent provides convenience methods for all HTTP verbs:

go 
// GET
resp := agent.Get("/path")

// POST with raw body
resp := agent.Post("/path", strings.NewReader("raw body"))

// POST with JSON
resp := agent.PostJSON("/users", map[string]string{"name": "John"})

// POST with form data
resp := agent.PostForm("/login", url.Values{"user": {"john"}, "pass": {"secret"}})

// PUT / PUT with JSON
resp := agent.Put("/users/1", body)
resp := agent.PutJSON("/users/1", user)

// PATCH / PATCH with JSON
resp := agent.Patch("/users/1", body)
resp := agent.PatchJSON("/users/1", partial)

// DELETE
resp := agent.Delete("/users/1")

// HEAD
resp := agent.Head("/path")

// OPTIONS
resp := agent.Options("/path")

// Generic — any method
resp := agent.Do("TRACE", "/path", nil)

Headers and Cookies

Set persistent headers or cookies that apply to all subsequent requests:

go 
agent := rue.NewAgent(r)

// Set headers (persists across requests)
agent.SetHeader("Authorization", "Bearer token123")
agent.AddHeader("Accept", "application/json")

// Set cookies
agent.SetCookie(&http.Cookie{Name: "session", Value: "abc"})

// Clear when done
agent.ClearHeaders()
agent.ClearCookies()

Request Builder

For complex requests, use the fluent builder:

go 
resp := agent.NewRequest("POST", "/search").
    Query("q", "test").
    Query("page", "1").
    Header("X-Custom", "value").
    JSON(map[string]string{"filter": "active"}).
    Send()

// Form data via builder
resp := agent.NewRequest("POST", "/upload").
    Header("X-Request-ID", "req-001").
    Form(url.Values{"field": {"value"}}).
    Send()

AgentResponse

Every request returns an AgentResponse with these fields and methods:

Field / MethodDescription
resp.StatusCodeHTTP status code (int)
resp.HeadersResponse headers (http.Header)
resp.BodyRaw response body ([]byte)
resp.CookiesResponse cookies ([]*http.Cookie)
resp.String()Body as string
resp.JSON(&v)Unmarshal body into struct/map

Full Example

go 
func TestUserCRUD(t *testing.T) {
    r := rue.New()
    setupRoutes(r)
    agent := rue.NewAgent(r)
    agent.SetHeader("Content-Type", "application/json")

    // Create
    resp := agent.PostJSON("/api/users", map[string]string{
        "name":  "Alice",
        "email": "alice@example.com",
    })
    assert(t, resp.StatusCode == http.StatusCreated)

    var created map[string]any
    resp.JSON(&created)
    id := created["id"].(string)

    // Read
    resp = agent.Get("/api/users/" + id)
    assert(t, resp.StatusCode == http.StatusOK)

    // Update
    resp = agent.PutJSON("/api/users/"+id, map[string]string{
        "name": "Alice Updated",
    })
    assert(t, resp.StatusCode == http.StatusOK)

    // Delete
    resp = agent.Delete("/api/users/" + id)
    assert(t, resp.StatusCode == http.StatusNoContent)

    // Verify gone
    resp = agent.Get("/api/users/" + id)
    assert(t, resp.StatusCode == http.StatusNotFound)
}

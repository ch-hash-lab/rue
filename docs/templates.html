HTML Templates

Rue provides powerful HTML template loading with support for multi-level directories, custom delimiters, and embedded file systems.

Basic Usage

Load templates from a glob pattern:

go 
r := rue.New()

// Load all HTML files from templates directory
r.LoadHTMLGlob("templates/*.html")

r.GET("/", func(c *rue.Context) {
    c.HTML(http.StatusOK, "index.html", rue.H{
        "title": "Welcome",
        "name":  "Rue",
    })
})

r.Run(":8080")

Multi-Level Directory Loading

Use ** pattern to load templates from nested directories:

go 
// Directory structure:
// templates/
// ├── layouts/
// │   ├── base.html
// │   └── admin.html
// ├── pages/
// │   ├── home.html
// │   └── about.html
// └── partials/
//     ├── header.html
//     └── footer.html

// Load all HTML files recursively
r.LoadHTMLGlob("templates/**/*.html")

// Templates are named by relative path:
// - "layouts/base.html"
// - "pages/home.html"
// - "partials/header.html"

r.GET("/", func(c *rue.Context) {
    c.HTML(http.StatusOK, "pages/home.html", rue.H{
        "title": "Home",
    })
})

Loading Specific Files

Load specific template files:

go 
r.LoadHTMLFiles(
    "templates/index.html",
    "templates/about.html",
    "templates/contact.html",
)

// Templates are named by filename only:
// - "index.html"
// - "about.html"
// - "contact.html"

Embedded File System

Load templates from embed.FS for single-binary deployment:

go 
import "embed"

//go:embed templates/*
var templateFS embed.FS

func main() {
    r := rue.New()

    // Load from embedded FS with glob patterns
    r.LoadHTMLFS(templateFS, "templates/*.html")

    // Or load recursively
    r.LoadHTMLFSRecursive(templateFS, "templates", "*.html")

    r.Run(":8080")
}

Custom Delimiters

Change template delimiters to avoid conflicts with frontend frameworks:

go 
r := rue.New()

// Use [[ ]] instead of {{ }}
r.Delims("[[", "]]")
r.LoadHTMLGlob("templates/*.html")

// In template:
// <h1>[[ .title ]]</h1>

Template Functions

Add custom functions to templates:

go 
import "html/template"

r := rue.New()

// Set custom functions before loading templates
r.SetFuncMap(template.FuncMap{
    "formatDate": func(t time.Time) string {
        return t.Format("2006-01-02")
    },
    "add": func(a, b int) int {
        return a + b
    },
    "multiply": func(a, b int) int {
        return a * b
    },
})

r.LoadHTMLGlob("templates/*.html")

// In template:
// <p>Date: {{ formatDate .createdAt }}</p>
// <p>Total: {{ multiply .price .quantity }}</p>

Built-in Template Functions

Rue provides common template functions via DefaultFuncMap:

Function Description Example
safe Mark string as safe HTML {{ safe .html }}
safeJS Mark string as safe JavaScript {{ safeJS .script }}
safeCSS Mark string as safe CSS {{ safeCSS .style }}
safeURL Mark string as safe URL {{ safeURL .link }}
upper Convert to uppercase {{ upper .name }}
lower Convert to lowercase {{ lower .name }}
title Title case {{ title .name }}
trim Trim whitespace {{ trim .text }}
join Join slice with separator {{ join .items ", " }}

go 
// Use default functions
r.SetFuncMap(rue.DefaultFuncMap)
r.LoadHTMLGlob("templates/*.html")

Rendering Templates

Render templates in handlers:

go 
r.GET("/users/:id", func(c *rue.Context) {
    user := getUser(c.Param("id"))

    c.HTML(http.StatusOK, "user.html", rue.H{
        "title": "User Profile",
        "user":  user,
        "now":   time.Now(),
    })
})

// With nested templates (multi-level loading)
r.GET("/admin/dashboard", func(c *rue.Context) {
    c.HTML(http.StatusOK, "admin/dashboard.html", rue.H{
        "stats": getStats(),
    })
})

Custom Template

Set a pre-configured template:

go 
import "html/template"

// Create custom template
tmpl := template.Must(template.New("").
    Delims("[[", "]]").
    Funcs(template.FuncMap{
        "custom": myCustomFunc,
    }).
    ParseGlob("templates/*.html"))

r := rue.New()
r.SetHTMLTemplate(tmpl)

// Get current template
currentTmpl := r.GetHTMLTemplate()

Complete Example

go 
package main

import (
    "html/template"
    "net/http"
    "time"

    "github.com/ch-hash-lab/rue"
)

func main() {
    r := rue.Default()

    // Custom functions
    r.SetFuncMap(template.FuncMap{
        "formatDate": func(t time.Time) string {
            return t.Format("Jan 02, 2006")
        },
        "year": func() int {
            return time.Now().Year()
        },
    })

    // Load templates recursively
    r.LoadHTMLGlob("templates/**/*.html")

    r.GET("/", func(c *rue.Context) {
        c.HTML(http.StatusOK, "pages/home.html", rue.H{
            "title":   "Welcome to Rue",
            "message": "Fast and elegant Go web framework",
        })
    })

    r.GET("/blog/:slug", func(c *rue.Context) {
        post := getPost(c.Param("slug"))
        c.HTML(http.StatusOK, "pages/blog/post.html", rue.H{
            "title": post.Title,
            "post":  post,
        })
    })

    r.Run(":8080")
}

Template file templates/pages/home.html:

html 
<!DOCTYPE html>
<html>
<head>
    <title>{{ .title }}</title>
</head>
<body>
    {{ template "partials/header.html" . }}

    <main>
        <h1>{{ .title }}</h1>
        <p>{{ .message }}</p>
    </main>

    {{ template "partials/footer.html" . }}
</body>
</html>
💡 Tip

When using multi-level directory loading with **, templates are named by their relative path (e.g., pages/home.html), making it easy to organize large template collections.

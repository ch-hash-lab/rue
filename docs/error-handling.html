Error Handling

Rue provides structured error handling with typed errors, error wrapping, and customizable error handlers for consistent API responses.

The Error Type

The rue.Error type carries an HTTP status code, message, optional details, and an optional wrapped error:

go 
// Create a basic error
err := rue.NewError(http.StatusNotFound, "User not found")

// Add structured details
err = rue.ErrBadRequest.WithDetails(map[string]string{
    "field": "email",
    "reason": "invalid format",
})

// Wrap an underlying error
err = rue.ErrInternalServerError.WithError(dbErr)

// Override message
err = rue.ErrForbidden.WithMessage("Insufficient permissions for this resource")

Using Errors in Handlers

Abort a request with an error to trigger the error handler:

go 
r.GET("/users/:id", func(c *rue.Context) {
    user, err := db.FindUser(c.Param("id"))
    if err != nil {
        c.AbortWithError(http.StatusNotFound,
            rue.ErrNotFound.WithMessage("User not found").WithError(err))
        return
    }
    c.JSON(http.StatusOK, user)
})

// Collect multiple errors without aborting
r.POST("/batch", func(c *rue.Context) {
    for _, item := range items {
        if err := process(item); err != nil {
            c.Error(err)
        }
    }
    // Check accumulated errors
    if len(c.Errors) > 0 {
        c.JSON(http.StatusMultiStatus, rue.H{"errors": c.Errors})
        return
    }
    c.JSON(http.StatusOK, rue.H{"status": "all processed"})
})

Error Comparison

rue.Error implements errors.Is — two errors match when their status codes are equal:

go 
err := rue.ErrNotFound.WithMessage("custom message").WithError(dbErr)

errors.Is(err, rue.ErrNotFound)    // true — same status code
errors.Is(err, rue.ErrBadRequest)  // false

// Unwrap to access the underlying error
var rueErr *rue.Error
if errors.As(err, &rueErr) {
    log.Printf("HTTP %d: %s", rueErr.Code, rueErr.Message)
}

Custom Error Handler

Override the default error handler on the engine:

go 
r := rue.New()

// Use the built-in JSON error handler with debug info
r.ErrorHandler = rue.JSONErrorHandler(rue.IsDevMode())

// Or write your own
r.ErrorHandler = func(c *rue.Context, err error) {
    var rueErr *rue.Error
    if !errors.As(err, &rueErr) {
        rueErr = rue.ErrInternalServerError.WithError(err)
    }

    c.JSON(rueErr.Code, rue.H{
        "error": rue.H{
            "code":    rueErr.Code,
            "message": rueErr.Message,
            "details": rueErr.Details,
        },
        "request_id": c.GetHeader("X-Request-ID"),
    })
}

JSONErrorHandler

The built-in JSONErrorHandler returns consistent JSON error responses. In debug mode it includes the underlying error string:

go 
// Production: hides internal errors
r.ErrorHandler = rue.JSONErrorHandler(false)
// Response: {"code": 500, "message": "Internal Server Error"}

// Development: exposes error details
r.ErrorHandler = rue.JSONErrorHandler(true)
// Response: {"code": 500, "message": "Internal Server Error", "error": "dial tcp: connection refused"}
Validation Errors

The default error handler also recognizes ValidationErrors and returns them as a 400 response with structured error details. See Validation for more.

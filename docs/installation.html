Installation

Rue requires Go 1.21 or later.

Using go get

go get github.com/ch-hash-lab/rue

Using go mod

Add to your go.mod:

require github.com/ch-hash-lab/rue latest

Then run:

go mod tidy

Dependencies

Rue has minimal dependencies:

  • sonic - High-performance JSON encoding/decoding
  • brotli - Brotli compression
  • quic-go - QUIC/HTTP3 support (optional)
  • grpc - gRPC support (optional)
